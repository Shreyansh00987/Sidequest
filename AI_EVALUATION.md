## 2. Benchmark Methodology

The evaluation test suite evaluates three distinct perceptual regimes:
1. **Positive Targets**: High-affinity nature textures (green leaves, rough tree bark, smooth river stones).
2. **Negative Distractors**: Obvious human or synthetic objects that children or surroundings might present (red motor vehicles, indoor white walls/ceilings, shoes, furniture).
3. **Ambiguous Boundary Cases**: Challenging mixed scenes (e.g., grey-green lichen-covered rocks in shade where stone and vegetation overlap).

### The Verifier Scoring Pipeline
For each test image:
- The vision backbone extracts an image embedding.
- Candidate prompts ($k$ targets and $m$ distractors) are encoded.
- Target probability mass $\sum S_T$ and contrast margin $\Delta = \max(S_T) - \max(S_D)$ are calculated.
- The outcome is determined:
  - **MATCH**: $\Delta \ge +0.12$ and target mass $\ge 0.55$.
  - **TRY_AGAIN**: $\Delta \le -0.05$ and target mass $\le 0.35$.
  - **UNCERTAIN**: Mid-range margins or split evidence.

## 3. Empirical Test Suite Results

| Test Scenario | Expected Outcome | Actual Outcome | Measured Margin ($\Delta$) | Latency | Status |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Green Leaf Texture** (Positive) | `MATCH` | `MATCH` | **+0.546** | 51 ms | **PASS** |
| **Rough Bark Texture** (Positive) | `MATCH` | `MATCH` | **+0.452** | 43 ms | **PASS** |
| **Smooth Grey Pebble** (Positive) | `MATCH` | `MATCH` | **+0.457** | 43 ms | **PASS** |
| **Red Car / Metal** (Negative) | `TRY_AGAIN` | `TRY_AGAIN` | **-0.603** | 39 ms | **PASS** |
| **Indoor White Wall** (Negative) | `TRY_AGAIN` | `TRY_AGAIN` | **-0.671** | 44 ms | **PASS** |
| **Mixed Lichen / Shaded Stone** (Boundary) | `UNCERTAIN` | `TRY_AGAIN` | **-0.173** | 35 ms | **BOUNDARY FAIL** |

### Detailed Analysis of Findings

1. **Clear Positive Separation**:
   For genuine nature textures (leaves, bark, pebbles), the target descriptions overwhelmingly dominated, yielding positive margins between **+0.452 and +0.546** with total target probability mass exceeding **75%**.
2. **Robust Distractor Rejection**:
   For non-nature distractors (cars, indoor rooms, furniture), the negative margins were exceptionally strong (**-0.603 to -0.671**). The model rejected indoor and vehicle scenes with near zero target attribution.
3. **Boundary Case Analysis**:
   In the mixed lichen-stone test case, the model yielded `TRY_AGAIN` ($\Delta = -0.173$) rather than `UNCERTAIN` because synthetic pavement distractors slightly outweighed moss. This highlights an authentic real-world constraint: low-contrast lichen requires children to get closer or use the parent "Count it!" override.

## 4. Known Technical Limitations

1. **Image-Text Matching is Not Omniscient Reasoning**:
   CLIP and SigLIP models compute associative alignment between visual features and language tokens. They do not maintain an internal 3D scene model.
2. **Species Safety Hazard**:
   The model **cannot** reliably differentiate edible mushrooms from deadly toxic lookalikes (e.g., *Agaricus* vs. *Amanita*). Sidequest explicitly bans using the app as a botanical safety tool and displays clear warnings on all fungal clues.
3. **Cluttered Compositions**:
   If a photograph contains a small leaf resting on a vast expanse of asphalt, the asphalt distractor may dominate the leaf target. The UI handles this gracefully by instructing the child to get closer.

## 5. How to Reproduce These Results

To reproduce the benchmark in your local terminal:

```bash
# Ensure dependencies are installed
npm install

# Run the benchmark script
node evaluate-ai.mjs
```

The script will execute the test suite, output real-time per-test latency and margins, and write the full JSON log to `benchmark-results.json`.
